GW006 IR UNIVERSAL — CHECKPOINT CP-04 / REV8 — 11/11/2026
=======================================================

HARDWARE / LIMITI NON MODIFICABILI
- Scheda Tuya GW006, modulo WBRG1/RTL8721CSM.
- OpenBeken 1.18.321 resta funzionante e non è stato modificato.
- Collegamenti storici PA19 TX / PA18 RX: UART0, NON documentati come
  pin IR nativi. Nessun ricablaggio né firmware flashati.
- Firmware installabile RTL8721CSM: non disponibile.
- Nessuna credenziale inserita nel codice; TCP del progetto NON autenticato.

BASE E FUNZIONALITA'
- REV7: core GWIR protocol v3, TX code conversion and FIFO pump, RX_ACK,
  up to five temporary IR frames with max 2048 pulses each; Kotlin/JVM
  durable storage model for 96 buttons, not Android APK.
- REV8: native-style RX bridge Realtek IR_GetRxDataLen/IR_ReceiveData,
  ISR software ring of 512 events, conversion RX counter tick->us,
  low/high active MARK polarity, idle detection, builder/engine integration.
- RX overrun/error: discard partial frame until a subsequent idle gap.
- RX worker requires real IR IRQ masking callbacks from board firmware.
- RX captures use a configured *guess* for carrier/duty, NOT measured value.

TEST REPLICATI E VERIFICATI NELL'AMBIENTE
- make test GCC: PASS for engine, stream, TX FIFO, TX codec, RX FIFO, TCP.
- make test with Clang -fsanitize=address,undefined: PASS.
- make test-kotlin: PASS (JVM only).
- make arm-smoke: PASS; ten unlinked ARM EABI .o for Cortex-M23 and
  Cortex-M33, using test stub ameba_soc.h and no official SDK link.
- RX tests include idle/long-space framing, inactive polarity, 32-word
  vendor FIFO, partial-frame rejection, overflow, resync, 900 events
  of queue index wrap-around.
- Host sizeof: engine 49,280B; RX queue 4,108B; RX worker 8,280B.
  Together ~61,668B, excluding other modules and task stacks.
  Target memory layout is NOT verified.
